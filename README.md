# FiberSense: анализ данных распределённых волоконно-оптических датчиков

Проект для хакатона «Анализ данных распределённых волоконных сенсоров».

## Основная задача

Исследовать структуру двух CSV (`4.csv`, `5.csv`), определить статистически нормальный режим, найти подозрительные события, проверить корреляции между пространственными зонами. По исходным CSV невозможно доказать наличие физического повреждения кабеля — единицы X/Y, спецификация прибора и подтверждённые метки неисправностей неизвестны.

## Установка и запуск

Требуется Python 3.10+.

1. Скачайте и распакуйте ZIP.
2. Поместите `4.csv` и `5.csv` в каталог **рядом с папкой FiberSense_RU** (исходные CSV не включены в архив из-за размера).
3. Установите зависимости: `pip install -r requirements.txt`.
4. Для полного пересчёта и генерации всех материалов выполните `python build_ru.py`.
5. Для отдельных шагов: `python analysis.py --data-dir .. --out-dir .`; затем `python localize_events.py`, `python visuals.py --data-dir .. --out-dir .`, `python make_report.py`, `python make_demo_html.py --data-dir .. --out-dir .`.
6. Для интерактивного приложения: `streamlit run dashboard.py`.

**Быстрый показ:** просто откройте `dashboard_demo.html` в браузере; данные для демонстрации уже встроены.

## Алгоритм выделения событий

1. Разобрать JSON-массив `points` в матрицу «измерение × координата X».
2. Исключить значения `-300` как условный код отсутствия измерения и недостающие значения неполных профилей.
3. Рассчитать медиану каждой позиции X; вычесть общий пространственный сдвиг каждого измерения.
4. Оценить устойчивое отклонение как `sigma_robust = 1.4826 × MAD`.
5. Выделить точки, где `abs(ΔY) > max(3, 5 × sigma_robust)`.
6. Сгруппировать смежные точки на сетке «время × X»; исключить слишком маленькие компоненты.
7. Выгрузить время, координаты, пик, продолжительность и внутренний балл события.

Параметры 3 и 5 — **исследовательские гиперпараметры**, а не допустимая температура для конкретного типа кабеля.

## Особенности исходных данных

- `4.csv`: 708 профилей, обычно 1691 точка; 10 укороченных профилей, 10 удлинённых интервалов времени. Время содержит UTC-смещение.
- `5.csv`: 2711 профилей, 2364 координаты в каждой записи; последние 675 координат всегда `-300` и исключаются. Временная зона не указана.
- По умолчанию в итогах выделяются 46 и 81 кластеры повышения соответственно: это **подозрения**, не подтверждённые аварии.
- Корреляции рассчитываются отдельно в каждом файле для 10 зон, в исходных рядах, после удаления линейного тренда и по первым разностям.

## Ограничения и вопросы к организаторам

Каковы единицы X и Y? Как устроена пространственная привязка? Что означает `-300` по паспорту прибора? Имеются ли метки событий, журнал эксплуатации, погодные данные и токовая нагрузка? Без этих сведений нельзя интерпретировать результаты как заключение о безопасности.
